title: Create and manage a training module
description: Teacher guide to creating a module, configuring tasks and resources, publishing training and grading submissions.

A module holds several tasks and their resources. Once published, each student claims their own environment and works inside it. The following workflow uses “Software Testing · Week 3” as an example.

## 1. Create a module

Go to **Modules → New** and enter the module name, date range and target class. New modules are drafts and are not visible to students.

## 2. Configure tasks and resources

1. On the module page, select **Add task** and enter the task requirements and expected duration;
2. Upload handouts and templates under **Resources** — students download them inside the environment;
3. Use the arrows to reorder tasks; students see them in that order.

> List the required deliverables, such as a test report and defect records, so each item can be assessed consistently.

## 3. Organise students into groups

Groups organise students and control group-level switches. Environments are assigned individually; each student receives an independent container. Add a whole class at once or assign students individually.

## 4. Publish the module and start environments

After publication, the module appears under **My training**. Students select **Open environment** and usually receive a URL and account within 30 seconds.

> Before class, start an environment and verify that the account works, the data is correct, and defect switches are applied to the intended groups.

## 5. Review and grade

Reports cannot be edited after submission. Grade each report and provide feedback; students receive an in-app notification. Export the grade sheet from **Reports and grading** at the end of term.

## Common questions

**Can I copy a module from the previous term?** This version does not support module copying. Create a new module and add the required tasks and resources.

**Can different groups receive different levels of difficulty?** Yes. Configure defect switches by group or student. The task structure can remain the same while the injected defects vary.
