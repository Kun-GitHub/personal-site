大肥鱼项目实训平台把项目镜像、训练任务、环境与报告串成教学流程。教师配置模块与小组，学生按课程安排使用独立或共用环境，再提交个人报告供教师评阅。平台不限定某一种被测系统。

[产品官网](https://training.wkong.kdns.fr)提供产品介绍；学校部署的登录地址请向本校管理员确认。

## 按角色查阅

- **教师**：[训练模块创建与管理](/docs/training-platform/guide/teacher/)介绍任务与资源、环境组合、分组、发布、归档和评分。
- **学生**：[任务执行与报告提交](/docs/training-platform/guide/student/)介绍开环境、共用环境、个人环境与报告操作。
- **学校管理员**：准备本机或 SSH Docker 资源节点、镜像与 CPU/内存规格，维护账号、班级和权限。环境与队列排查见[常见问题](/docs/training-platform/faq/)。

## 当前能力与边界

### 多节点资源池与环境编排

平台可将本机 Docker 与通过 SSH 连接的远程 Docker 纳入资源池。自动调度只选择镜像已就绪、未离线且有容量的节点；CPU 与内存按节点容量的 80% 上限预留，通过事务防止并发重复占用。也可显式指定节点，指定后排队仍保留该节点，不会转投其他节点。

教师在「训练模块（Modules）」的「环境组合（Environments）」中设置节点、镜像和规格，并选择默认的打散策略（`spread`）或集中放置策略（`binpack`）。这些策略决定新环境的放置顺序，不会搬迁已有实例。

### 每人一台或每组共用

模块默认每人一台（`per_student`），也可每组共用一台（`per_group`）；「训练小组（Groups）」的编辑页可覆盖模块设置。当前组员都能查看共用实例详情、访问信息并使用终端；退出小组后不再拥有该共用实例的访问权。学生即使是最初创建者，也不能重置、销毁或删除共用环境，这些操作需要教师或管理员具备环境管理权限。

个人环境不关联模块或小组，同一用户可创建多台。它与按模块复用的训练环境不同。

### 队列与故障隔离

容量不足时请求进入队列，每个模块最多 20 个待处理请求，排队超过 10 分钟会失败；教师和管理员优先。界面约每 5 秒更新待处理状态，后台默认每分钟派发一次，排队期间不会创建实例数据库。

多节点高可用仅指**资源节点故障隔离**，不包含平台服务或数据库主备。故障节点上的已有实例不会迁移或自动接管；出现 `error.serverOffline` 后需删除失败实例并重新创建，共用实例由有管理权限的教师或管理员处理。

### 镜像决定访问与数据能力

环境详情显示端口与访问方式，并不保证每种镜像都有业务网页、账号或测试数据。Alpine 通常使用终端，Nginx 提供 HTTP 服务，Redis、MySQL 与 PostgreSQL 使用各自协议；请按镜像说明和课程要求访问。开关能力也由镜像实现，平台不内置某个项目的缺陷清单。

只有镜像启动命令使用 `APP_DB_NAME` 且学校部署已配置 `instance_db` 时，平台才按需建立独立数据库；表结构与初始数据由镜像应用负责。重置不是数据库还原，数据保留也不能对所有镜像一概保证。操作前请备份，详见[常见问题](/docs/training-platform/faq/)。

## 授权与开源边界

**平台闭源，按校授权私有化部署**，不是公开代码仓库。实际数据存放位置与运维责任由学校的部署方案决定。

示例项目**大肥鱼 ERP**的代码采用 MIT 许可，可从 [GitHub（国外）](https://github.com/training-image-marketplace/Dafeiyu-erp) 或 [Gitee（国内）](https://gitee.com/training-image-marketplace/Dafeiyu-erp) 获取；MIT 不授予「大肥鱼」名称与商标使用权。ERP 可配套 Android 客户端，其接入要求以独立镜像项目仓库的契约为准。其他镜像遵循各自上游许可，不能统称为 MIT。
